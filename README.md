# 小狗日报 · 编辑部工作台

> The Daily Woof — 一个复古报刊风格的个人工作台。

单文件 HTML，双击即用，无需安装或构建。数据保存在浏览器 localStorage 中。

## 主题

- **卡通小狗 × 复古报刊编辑部**
- 米白色旧报纸底纹、浅棕色墨褐文字、橘黄与墨绿色点缀
- 手绘小猫、纸胶带、邮票边框、铅笔批注等装饰元素

## 模块

| 模块 | 角色 |
|---|---|
| 今日截稿 | 待办清单（头版/要闻/副刊三级优先级） |
| 编辑部日常 | 习惯打卡 |
| 阅读稿 | 书籍进度 |
| 外勤 | 运动/锻炼记录 |
| 社务账 | 记账本（收入/支出/占比） |
| 副刊随笔 | 日记/心情 |
| 今日看点 | 热点收藏/稍后读 |

## 使用方式

1. 下载仓库或复制 `workbench-desktop.html` + `assets/` 到同一目录
2. 双击 `workbench-desktop.html` 在浏览器中打开
3. 可直接开始记录，数据自动保存在本机浏览器中

## 重要提醒

**所有数据仅保存在你当前设备的当前浏览器中。**
换电脑、换浏览器、或清除浏览记录会导致数据丢失。重要内容请定期手动备份。

## 素材

插画使用 AI 生成（柯基头像、手绘小猫贴纸、报纸编辑室横幅），风格统一。
